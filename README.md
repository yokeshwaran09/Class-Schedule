# Class Timetable

A weekly class timetable (Monday to Saturday) created using HTML tables. This is a beginner-friendly project that shows how to use `rowspan` and `colspan` to build a real-world table layout.

## Features

- Weekly schedule from Monday to Saturday
- Period timings from 8:30 AM to 3:50 PM
- Merged cells for breaks, lunch, and lab sessions
- Colour-coded header, breaks, and lunch
- Simple, single-file HTML page with no extra libraries
